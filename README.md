# 📚 Book Recommender System

A machine learning-based Book Recommender System that suggests books to users based on their preferences, ratings, and reading history. The project helps users discover new books they may enjoy using recommendation algorithms.

## 🚀 Features

- Recommend books based on user preferences
- Popularity-based recommendations
- Collaborative filtering recommendations
- Search for books by title
- User-friendly interface
- Displays book cover images, author names, and ratings

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit / Flask 
- Jupyter Notebook
- Pickle
